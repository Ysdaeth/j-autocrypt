# EncryptionManager
`CORE MODULE`

Is responsible for data encryption based on the provided [AlgorithmIdentifier](../api/1.AlgorithmIdentifier.md)
and to automate algorithm selection for backward operation

## How to use
Encryption manager operates with [Encryptor](../api/4.Encryptor.md) 

First we need to create the CryptographicRegistry for encryptors.
You should definitely check out the [CryptographicRegistry](1.CryptographicRegistry.md) docs.

### Create registry
```java
Encryptor myEncryptor = new Encryptor(){ ... };
CryptographicRegistry<Hasher> registry = new CryptographicRegistry();
registry.register(myEncryptor);
```
> [!NOTE]
> encryptor implementations are available as modules and packages
> [Implementations](../implementations/0.Implementations.md)

### Create EncryptionManager instance.
```java
EncryptionManager encryptionManager = new EncryptionManager(registry);
```

### Encryption and decryption
Let's assume that our `Encryptor`uses [AlgorithmIdentifier](../api/1.AlgorithmIdentifier.md)
bytes 0x01 and 0x01.

```java
byte algorithmType = 0x01;
byte algorithmVariant = 0x01;
AlgorithmIdentifier myEncryptorId = new AlgorithmIdentifier(algorithmType, algorithmVariant);

byte[] data = "message".getBytes();
SecretKey secretKey = KeyGenerator.getInstance("myAlgorithmInstance").generateKey();

AlgorithmOutput output = encryptionManager.encrypt(data, secretKey, nonKeyedId);
byte[] decrypted = encryptionManager.decrypt(output, secretKey);
```
After calling `decrypt`, the manager automatically selects algorithm instance. In our case there was only one
`Encryptor`, but when there are more encryptors, you'd need to select a proper one. Also, let's assume, that our `Encryptor`
might be AES GCM, in that case we would need to store initial vector, but here metadata is computed and can
be reused for decryption, even if current parameters change.


## Constructor
Constructor
```java
public EncryptionManager(CryptographicRegistry<Encryptor>)
```

## Encrypt
Algorithm implementation will be selected based on the provided [AlgorithmIdentifier](../api/1.AlgorithmIdentifier.md)
assigned to the algorithm instance. When there is no registered instance, the AlgorithmIdentificationException will 
be thrown.
```java
public AlgorithmOutput encrypt(byte[] data, AlgorithmIdentifier identifier, Key key)
        throws KeyException, AlgorithmIdentificationException
```

## Decrypt
Decrypts algorithm output produced by the `Encryptor`. It automatically resolves algorithm instance and pass
all metadata required for decryption
```java
public boolean decrypt(AlgorithmOutput output, Key key) 
        throws AlgorithmIdentificationException, KeyException
```
