# HashingManager
`CORE MODULE`

Is responsible for data hashing based on the provided [AlgorithmIdentifier](../api/1.AlgorithmIdentifier.md) 
and to automate algorithm selection for hash comparison

## How to use
Hashing manager operates with [KeyedHasher](../api/6.KeyedHasher.md) and [Hasher](../api/5.Hasher.md), because hashes 
can be created with a cryptographic keys and without them.

First we need to create the CryptographicRegistry for both hasher types. 
You should definitely check out the [CryptographicRegistry](1.CryptographicRegistry.md) docs.

### Create registry 
```java
Hasher myHasher = new Hasher(){ ... };
CryptographicRegistry<Hasher> nonKeyedRegistry = new CryptographicRegistry();
nonKeyedRegistry.register(myHasher);

KeyedHasher myKeyedHasher = new KeyedHasher(){ ... };
CryptographicRegistry<KeyedHasher> keyedRegistry = new CryptographicRegistry();
keyedRegistry.register(myKeyedHasher);
```
> [!NOTE]
> Hasher and KeyedHasher implementations are available as modules and packages 
> [Implementations](../implementations/0.Implementations.md)

### Create HashingManager instance.
```java
HashingManager hashingManager = new HashingManager(keyedRegistry, nonKeyedRegistry);
```
### Hash and verify 
Let's assume that our no-keyed `Hasher`uses [AlgorithmIdentifier](../api/1.AlgorithmIdentifier.md) 
bytes 0x80 and 0x01.

```java
byte algorithmType = 0x80;
byte algorithmVariant = 0x01;
AlgorithmIdentifier nonKeyedId = new AlgorithmIdentifier(algorithmType, algorithmVariant);
byte[] data = "message".getBytes();

AlgorithmOutput output = hashingManager.hash(data, nonKeyedId);
boolean matches = hashingManager.matches(data, output);
```
After calling `matches`, the manager automatically selects algorithm instance. In our case there was only one
`Hasher`(non-keyed), but when there are more hashers, you'd need to select a proper one. Also, let's assume, that our `Hasher` 
might be Argon2, in that case we would need to store salt, iterations etc. but here metadata is computed and can 
be recalculated dynamically, even if current parameters change.


## Constructor
Constructor is overloaded if you need only `KeyedHasher` registry, `Hasher` registry or `both`
```java
public HashingManager(CryptographicRegistry<KeyedHasher>, 
                      CryptographicRegistry<Hasher>)
    
public HashingManager(CryptographicRegistry<Hasher>)
    
public HashingManager(CryptographicRegistry<KeyedHasher>)
```

## Hash
Algorithm implementation will be selected based on the provided [AlgorithmIdentifier](../api/1.AlgorithmIdentifier.md) 
assigned to the algorithm instance. When there is no registered instance, the AlgorithmIdentificationException 
will be thrown.

Hash with key will call [KeyedHasher](../api/6.KeyedHasher.md) to create data hash with a key. 
```java
public AlgorithmOutput hash(byte[] data, AlgorithmIdentifier identifier, Key key)
        throws KeyException, AlgorithmIdentificationException
```

Hash without key will call [Hasher](../api/5.Hasher.md) to create data hash.
```java
public AlgorithmOutput hash(byte[] data, AlgorithmIdentifier identifier)
        throws AlgorithmIdentificationException
```

## Matches
Tests if the algorithm output produced by `Hasher` or `KeyedHasher` matches the raw data. It automatically resolves  
algorithm instance and pass all metadata required for hash recalculation
```java
public boolean matches(byte[] data, AlgorithmOutput encoded) 
        throws AlgorithmIdentificationException
```

or when algorithm requires a key
```java
public boolean matches(byte[] raw, AlgorithmOutput output, Key key)
        throws AlgorithmIdentificationException, KeyException
```
