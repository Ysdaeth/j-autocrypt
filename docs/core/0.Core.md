## CORE MODULE
Core module contains the core functionality of the library. These components
are responsible for selection of the cryptographic algorithm implementations to produce
[AlgorithmOutput](../api/2.AlgorithmOutput.md).  
When performing encryption or hashing, you must provide the [AlgorithmIdentifier](../api/1.AlgorithmIdentifier.md) and data to perform
cryptographic operation with selected algorithm.   
For decryption or hash verification the algorithm identifier is resolved from the encoded bytes, and proper
algorithm implementation is provided automatically. Metadata is computed into output bytes to provide backward operation
without need to store the metadata.

*Install the CORE package with maven:*
```xml
<dependency>
    <groupId>dev.ysdaeth.autocrypt</groupId>
    <artifactId>j-autocrypt-core</artifactId>
    <version>x.y.z</version>
</dependency>
```
