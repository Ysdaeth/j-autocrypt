# Encryptor AES GCM
`Encryptor implementation`

AES GCM uses java security provider to provide the algorithm instance.
Uses 128bit authentication tag and 96bit initial vector with SecureRandom.

## Create instance
```java
Encryptor aes =  new EncryptorAesGcm(AlgorithmIdentifier);
```

## Install
*Install package with maven:*
```xml
<dependency>
    <groupId>dev.ysdaeth.autocrypt</groupId>
    <artifactId>j-autocrypt-aes-gcm</artifactId>
    <version>x.y.z</version>
</dependency>
```
> [!WARNING]
> Collision chance for random 96bit initial vector is low, but not zero. Remember about the key rotations.
