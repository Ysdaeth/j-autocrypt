# Hasher HMac SHA
`KeyedHasher implementation`

Uses java security provider to provide the algorithm instance.
HMac with SHA224, SHA256, SHA384 and SHA512.

## Create instance

### HMac SHA224
```java
KeyedHasher hasher = HasherHMac.sha224(AlgorithmIdentifier)
```

### HMac SHA256
```java
KeyedHasher hasher = HasherHMac.sha256(AlgorithmIdentifier)
```

### HMac SHA384
```java
KeyedHasher hasher = HasherHMac.sha384(AlgorithmIdentifier)
```

### HMac SHA512
```java
KeyedHasher hasher = HasherHMac.sha512(AlgorithmIdentifier)
```

## Install
*Install package with maven:*
```xml
<dependency>
    <groupId>dev.ysdaeth.autocrypt</groupId>
    <artifactId>j-autocrypt-h-mac-sha</artifactId>
    <version>x.y.z</version>
</dependency>
```
