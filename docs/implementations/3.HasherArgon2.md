# HasherArgon2
`Hasher implementation`

Uses [Bouncy Castle Provider](https://www.bouncycastle.org/) to provide the algorithm instance.

## Create instance

### Argon2id

```java
KeyedHasher hasher = HasherArgon2.argon2id(identifier, iterations, parallelism, memKB, hashLength);
```

### Argon2i
```java
KeyedHasher hasher = HasherArgon2.argon2i(identifier, iterations, parallelism, memKB, hashLength);
```

### Argon2d
```java
KeyedHasher hasher = HasherArgon2.argon2d(identifier, iterations, parallelism, memKB, hashLength);
```

## Install
*Install package with maven:*
```xml
<dependency>
    <groupId>dev.ysdaeth.autocrypt</groupId>
    <artifactId>j-autocrypt-argon2</artifactId>
    <version>x.y.z</version>
</dependency>
```
