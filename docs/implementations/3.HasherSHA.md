# Hasher SHA
`Hasher implementation`

Uses java security provider to provide the algorithm instance.
SHA224, SHA256, SHA384, SHA512

Uses java security provider to provide the algorithm instance.

## Create instance

### SHA224
```java
Hasher hasher = HasherSha.sha224(AlgorithmIdentifier);
```
### SHA256
```java
Hasher hasher = HasherSha.sha256(AlgorithmIdentifier);
```
### SHA384
```java
Hasher hasher = HasherSha.sha384(AlgorithmIdentifier);
```
### SHA512
```java
Hasher hasher = HasherSha.sha512(AlgorithmIdentifier);
```

## Install
*Install package with maven:*
```xml
<dependency>
    <groupId>dev.ysdaeth.autocrypt</groupId>
    <artifactId>j-autocrypt-sha</artifactId>
    <version>x.y.z</version>
</dependency>
```
